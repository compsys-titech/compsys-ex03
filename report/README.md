## 4．課題Aを記録する

対象は`tasks/pseudo_task.s`．`BEGIN NEG`～`END NEG`と`BEGIN BLE`～`END BLE`の内側だけを編集する．マーカーそのものと範囲外は変更しない．

- **A1 置換前後の対応**：編集前の`neg`・`ble`に対応するRARSのBasic列を記録し，自分が書いたRV32I基本命令，各オペランドの役割，表記や命令列の違いを対応表へ記入する．複数命令の解も記録できる．
- **A2 同じ働きになる理由**：`neg`の符号反転，`ble`の符号付き比較と分岐条件，Basic列と自分の命令が異なる場合の同値性を，それぞれ数行で説明する．ABI名とx番号，ラベルと数値の表記差は，命令の働きの違いとは限らない．
- **A3 実行確認**：`make test-a`を実行し，以下の識別名ごとに実測結果，PASS／FAIL，必要な補足を記録する．動作ケースでは実際の2行出力を記録する（表内で改行するか，改行を明示する）．範囲・命令検査では表示された判定を記録する．

`A-SCOPE`，`A-RV32I`，`A-POS-LT`，`A-NEG-GT`，`A-ZERO-EQ`，`A-MIX-LT`，`A-MIX-GT`，`A-NEG-LT`，`A-NEG-PAIR-GT`，`A-ZERO-PAIR-EQ`，`A-ZERO-LEFT-GT`．

配布直後は未置換のため，動作ケースがPASSでも全体は`UNFINISHED`として非0終了する．実測していない結果をPASSとして記入しない．

## 5．課題Bを記録する

対象は`tasks/array_task.s`．`BEGIN TODO`～`END TODO`の内側だけを編集する．配列初期値，要素数，マーカー，範囲外を変更しない．ループ，`lw`，`sw`，条件分岐，算術命令を用いる．6回の処理複製，個別アドレスや計算結果のハードコード，関数呼出し，スタック，ヒープは使わない．レジスタ割当やループの数は自分で決めてよい．

- **B1 処理の概要**：アルゴリズム，ループ終了条件，配列アドレスの更新，負数判定，絶対値への変換，元配列への書戻し，合計更新，表示処理を簡潔に説明する．
- **B2 使用レジスタ**：レジスタ，役割，値またはアドレスの意味，主に使う処理を記入する．必要な行数を追加してよい．
- **B3 コードとの対応**：初期化，終了判定，読出し，負数判定，変換，書戻し，合計，表示，アドレス・カウンタ更新を，自分の命令・ラベルと対応付ける．
- **B4 実際の出力**：Run I/Oのプログラム出力2行を，読めるテキストで記録する．行頭・行末に余分な空白がなく，要素間は半角空白1個，両行末に改行があることを確認する．
- **B5 実行後の配列**：Run終了直後，**Reset・再Assemble前**にData SegmentでA[0]～A[5]の10進値を読む．メモリを直接書き換えない．
- **B6 実行確認**：`make test-b`の`B-SLIDE`，`B-MIXED`，`B-POSITIVE`，`B-NEGATIVE`について，LAYOUT／OUTPUT／MEMORYの実測判定を記録する．配布直後はTODO未実装なので非0終了する．

ソース全文をレポートへ重複掲載せず，説明に必要な短い箇所だけ示す．コードZIPの実装と説明・実測値を一致させる．

## 8．コードZIPを作成する

提出するZIPは，次の2ファイルだけを入れ，`tasks/`の階層を保持する．

```text
学籍番号_ex03_code.zip
└── tasks/
    ├── pseudo_task.s
    └── array_task.s
```

**GUIで作る場合**：リポジトリ外に空の提出用フォルダーを作り，その中に`tasks`フォルダーを作る．編集した`pseudo_task.s`と`array_task.s`の2ファイルだけをコピーする．この`tasks`フォルダーを選び，OSの「圧縮」「ZIPファイルに圧縮」等を使う．できたZIPを`学籍番号_ex03_code.zip`へ改名する．macOSではFinder，Windowsではエクスプローラー，GNU/Linuxでは利用環境のファイルマネージャーの圧縮機能を使える．追加ソフトウェアは必須ではない．

任意のコマンド例（教材ルートで実行）．`学籍番号`を自分の番号へ置き換え，出力先に同名のZIPがないことを確認する．既存ZIPへ追記しない．

macOS／GNU/Linuxで`zip`が使える場合：

```sh
zip -X "../学籍番号_ex03_code.zip" tasks/pseudo_task.s tasks/array_task.s
```

Windows PowerShell：

```powershell
Compress-Archive -LiteralPath .\tasks -DestinationPath ..\学籍番号_ex03_code.zip
```

PowerShell例の実行前に，`tasks`の中身が上記2ファイルだけであることを確認する．追加ファイルがある場合は，GUIの手順でリポジトリ外に2ファイルだけをコピーして圧縮する．

**作成後は必ず別の空フォルダーへZIPを展開する**．最上位に`tasks`があり，その中に上記2ファイルだけがあることを確認する．2ファイルを開き，自分の最終コードと一致することも確認する．`.DS_Store`や`__MACOSX`等の自動付加ファイルが見える場合も取り除き，2ファイルだけで作り直す．`zip`の例は指定した2ファイルだけを格納する．

`examples/`，`tests/`，`tools/`，`build/`，`report/`，`.git/`，README，Makefile，RARS JAR，ログ，dump，別の解答資料やその他の教材ファイルは含めない．
